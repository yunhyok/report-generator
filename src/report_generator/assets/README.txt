SPD Report Generator application icon

Original concept: a circuit connection, an impedance curve and a report table
combined on a charcoal tile. Generated with OpenAI's built-in image generation
tool for this project; no product data or third-party logo was used.

app-icon.png is the transparent master. app.ico preserves the artwork as Windows
icons at 16, 24, 32, 48, 64, 128 and 256 pixels. The icon assets use the project's
MIT license.
