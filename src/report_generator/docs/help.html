SPD REPORT GENERATOR · v0.1.18

입력 파일에서 Excel 보고서까지

SPD의 부품·모델·배치, Touchstone의 임피던스, 직접 입력한 DCR을 조합해 보고서를 만듭니다. 파일 처리는 이 PC에서 이루어지며 클라우드 업로드나 계정 연결이 필요하지 않습니다.

프로그램에서 Help → 사용 설명서 또는 F1로 이 문서를 엽니다. 프로그램 안의 전용 창에서 인터넷 없이 읽습니다. 목차·본문 링크와 뒤로·앞으로·목차 버튼으로 이동할 수 있습니다. 시작 메뉴의 Help도 같은 전용 창을 엽니다.

1. 처음 실행하기

  1. Windows x64용 SPD-Report-Generator-v0.1.18-Setup-x64.exe를 실행해 설치합니다. 설치에는 관리자 권한이 필요합니다. 기본 경로는 C:\Program Files\SPD Report Generator이며, 설치 화면에서 다른 드라이브나 폴더를 선택할 수 있습니다. 바탕 화면 바로가지는 설치 중 선택할 수 있습니다.
  2. 시작 메뉴에서 SPD Report Generator를 엽니다. 같은 메뉴의 Help로 이 설명서를 바로 열 수 있습니다.
  3. 1 입력에서 필요한 SPD·Touchstone 파일을 고르고 파일 읽기를 누릅니다. 제목, 제품명, 보드 종류와 작성일 등을 입력합니다.
  4. 2 채널·그룹에서 사용할 행을 고르고 Net·사이트·채널·SPD 포트를 확인합니다. 모호한 연결을 해결한 뒤 확인에 체크합니다.
  5. 순위를 지정하려면 채널 순위 설정…을 엽니다. 채널 옆 입력 칸을 클릭해 순위를 입력하고, 보고서에 적용할지 선택한 뒤 설정 저장을 누릅니다.
  6. 필요하면 3 CAP·DCR에서 용량을 수정하거나 DCR을 입력합니다.
  7. 4 미리보기·출력 → 미리보기 갱신으로 포함될 페이지를 살핀 뒤 Excel 저장…을 누릅니다.
파일이 모두 있어야 시작할 수 있는 것은 아닙니다. SPD만으로 CAP 수량·배치도를, Touchstone만으로 임피던스 보고서를, DCR 입력만으로 DCR 표를 만들 수 있습니다.

읽기와 출력 중에는 아래 진행 상태를 확인할 수 있습니다. 중단하려면 취소를 누릅니다. 파일을 새로 읽으면 자동 매핑을 다시 제안하고 CAP 수정값을 초기화하므로, 이어서 작업할 설정은 먼저 프로젝트로 저장하세요.

업데이트와 제거

v0.1.4에서 업데이트할 때는 작업을 저장하고 프로그램을 닫은 뒤 Windows 설정 → 앱 → 설치된 앱에서 기존 SPD Report Generator를 먼저 제거하세요. 그런 다음 새 설치 파일을 실행해 설치합니다. 프로젝트·보고서와 원본 입력 파일은 제거되지 않습니다. v0.1.5부터 기본 설치 위치는 C:\Program Files\SPD Report Generator이며, 설치 화면에서 다른 드라이브나 폴더를 선택할 수 있습니다.

제거하려면 Windows 설정 → 앱 → 설치된 앱에서 SPD Report Generator를 찾아 제거를 선택합니다. 직접 저장한 프로젝트·보고서와 원본 입력 파일은 제거하지 않습니다.

2. 입력과 지원 범위

입력사용하는 내용확인할 점
SPD부품의 실제 모델 할당, Net, 활성 상태, 모델 주석의 명목 용량, 위치·회전·면·몸체 치수와 연결된 표면 패드부분 회로와 연결 정보가 있는 텍스트 SPD를 사용합니다. 원본을 수정하지 않고 읽습니다.
Touchstone다중 포트 S 행렬을 변환한 자기 임피던스 |Zii|Touchstone 1.x, S 파라미터, RI·MA·DB, 확장자 .sNp, 최대 1024포트를 지원합니다. 2.x 키워드·혼합 모드는 지원하지 않습니다.
DCR사이트·채널별 직류 저항 표키가 포함된 표 붙여넣기·.xlsx 가져오기, 숫자 한 열, 표 직접 입력이 가능합니다.

Touchstone은 # 옵션 행, 0 이상의 중복 없는 오름차순 주파수, 완전한 주파수별 행렬이 필요합니다. 한 행 또는 한 주파수 기록은 64MiB 이하여야 합니다. 포트 수가 커지면 행렬 계산 시간도 늘어납니다.

SPD의 UTF-8 또는 CP949 식별자를 읽으며, 해독할 수 없는 식별자를 다른 문자로 바꿔 연결하지 않습니다. 한 파일을 읽지 못해도 다른 입력이 유효하면 해당 데이터로 작업할 수 있습니다. 화면 아래 로그에서 오류와 제외 사유를 확인하세요.

접지 Net (쉼표 구분)에는 추가 접지 이름을 입력할 수 있습니다. 예: GND, DGND, RETURN_A. SPD에 정의된 접지와 함께 CAP의 전원–접지 연결을 판단합니다. Net 이름과 명시된 alias 관계를 사용하며 비슷한 이름을 임의로 합치지 않습니다.

3. 채널·그룹 연결

자동 제안은 작업을 시작하기 위한 후보입니다. Touchstone 행렬의 포트 번호와 SPD의 포트 번호가 같다는 이유만으로 같은 연결이라고 판단하지 마세요. 이름이나 헤더의 포트 설명이 실제 추출 설정과 일치하는지 확인해야 합니다.

열의미
사용이번 보고서에 사용할 행입니다. 제외할 단자는 체크를 해제합니다.
요약PI ALL@100MHz와 PI ALL 요약에 포함합니다. 상세 그룹과 CAP 집계의 사용 여부는 사용 열로 결정합니다.
확인사용자가 연결을 검토했는지 표시합니다. 모호한 행은 확인 전 출력할 수 없습니다.
번호 / 원본 포트Touchstone의 행렬 포트 번호와 원본 설명입니다. SPD만 사용할 때 번호는 비어 있을 수 있습니다.
SPD 포트 / SPD Net (실제 연결)연결할 SPD 포트의 전체 이름과 대상 전원 Net. 알려진 SPD 포트 이름을 입력하면 실제 연결 Net이 채워짐.
사이트 / 채널예: SITE2 / POWER_A. 같은 사이트·채널에는 사용할 단자를 하나만 선택합니다.
그룹비워 두면 채널별 상세 그래프를 만들고 같은 채널의 사이트를 한 그림에 표시합니다. 여러 채널에 같은 그룹명을 지정하면 한 그래프로 묶습니다.
보고서 표시명보고서의 Channel 셀에 표시할 이름. 그룹을 비워 두면 개별 채널의 그래프 제목과 상세 시트 탭에도 사용. 직접 입력하거나 지울 수 있음. 실제 연결 Net·채널·사이트는 유지.
상태자동 제안·중복·원본 변경 등 연결을 확인해야 하는 이유를 표시합니다.

접두사가 같은 포트만 사용하기

검색란을 비우고 검색 결과 제외를 눌러 모든 행의 사용을 해제합니다. 그런 다음 LGA1-처럼 원하는 접두사를 검색하고 원본 포트 열을 확인한 뒤 검색 결과 사용을 누릅니다. 검색란을 비우면 전체 포트의 선택 상태를 다시 볼 수 있습니다.

같은 사이트·채널에 단자가 여러 개라면

예를 들어 SITE2 / POWER_A에 부하 측과 공급 측 포트가 모두 있으면 두 후보를 유지하고 확인을 요청합니다. 평균을 내거나 둘 중 하나를 자동으로 버리지 않습니다.

  1. 검색란에 사이트나 채널 이름을 입력해 후보를 좁힙니다.
  2. 원본 포트·SPD 포트·Net을 비교하고, 사용하지 않을 행의 사용 체크를 해제합니다. 검색 결과 사용 / 검색 결과 제외는 현재 보이는 행에 적용됩니다. 검색만으로 행이 제외되는 것은 아닙니다.
  3. 남길 행의 Net·사이트·채널을 수정하고 확인에 체크하거나, 행을 선택한 뒤 선택 행 확인을 누릅니다.
  4. 한 그래프로 묶을 행을 선택해 그룹명을 입력하고 그룹 적용을 누릅니다. 채널별로 다시 나누려면 그룹명을 비워 적용할 것.

행을 고르는 것과 사용 체크는 별개입니다. 여러 행은 Ctrl 또는 Shift로 선택할 수 있습니다. 채널 추가로 직접 행을 만들고 선택 행 삭제로 지울 수 있습니다. 같은 Touchstone 포트를 여러 행에서 사용하거나 사이트·채널을 중복 선택하면 출력 전에 수정해야 합니다.

SPD 포트·실제 연결 Net·사이트·채널을 바꾸면 확인 체크가 해제됩니다. 연결을 다시 검토한 뒤 확인해 주세요. 그룹·Priority·보고서 표시명만 바꾸면 기존 확인 상태를 유지합니다. 입력한 SPD 포트가 원본에 없으면 확인과 출력을 막습니다.

채널 순위와 순위 외 구간

  1. 채널 순위 설정…을 열고 채널 이름 옆 입력 칸을 한 번 클릭합니다. 1, 2처럼 숫자를 입력합니다. 같은 숫자는 동순위입니다. Tab을 누르면 다음 채널로, Shift+Tab을 누르면 이전 채널로 이동합니다.
  2. 순위 없이 묶을 채널에는 보조 전원처럼 같은 구분명을 입력합니다. 빈칸은 미순위입니다. 한 채널에 입력한 값은 그 채널의 모든 사이트에 적용됩니다.
  3. 보고서에 반영하려면 PI·CAP·DCR 표와 개별 채널 상세 순서에 적용을 체크하고 설정 저장을 누른 뒤 미리보기 갱신을 실행합니다. 체크를 꺼 둔 채로도 값을 입력하고 보관할 수 있습니다. 다음 작업에서 다시 쓰려면 프로젝트를 저장하세요.

PI·CAP·DCR 표와 개별 채널의 상세 그래프·Excel 상세 시트는 숫자 순위가 낮은 채널부터 표시합니다. 이어서 구분명별 채널과 미순위 채널을 표시합니다. 직접 지정한 그룹은 해당 묶음으로 표시합니다.

Excel에서 순위·그룹·보고서 표시명 입력하기

  1. 2 채널·그룹에서 대상 행의 사용을 체크하고 채널·사이트를 채운 뒤 Excel 양식 저장…을 누를 것. 양식에는 사용 중인 원래 채널명·사이트 조합만 중복 없이 저장되며, priority·group·net은 빈칸으로 제공.
  2. Excel의 첫 번째 워크시트에서 1행 제목을 유지하고 2행부터 필요한 값을 입력할 것. priority는 순위·구분명, group은 상세 그래프 묶음, net은 보고서 표시명. .xlsx로 저장할 것. 파일 이름·행 순서·열 위치는 자유이며, 1행 제목으로 열을 찾음. 제목의 앞뒤 공백·영문 대소문자는 구분하지 않음. 채널명·사이트 대신 channel·site도 사용 가능.
  3. 탐색기에서 저장한 .xlsx 파일 하나를 2 채널·그룹 화면에 끌어다 놓을 것. Excel 설정 불러오기…로도 같은 파일을 선택할 수 있음. 미리보기 갱신으로 확인한 뒤 다음 작업에서도 쓰려면 프로젝트 저장을 실행할 것.
가상 예: net·group·priority 순서로 배치하고 필요한 값만 입력
채널명사이트netgrouppriority
POWER_ASITE1Core_Power_001전원 A1
POWER_ASITE2Core_Power_001전원 A
POWER_BSITE0전원 B2

priority·group·net 중 필요한 열만 남길 것. 선택 열은 하나 이상 필요하며, net만 있는 파일이나 기존 priority·group 양식도 사용 가능. 빈 셀·생략한 열·파일에 없는 행은 기존 값을 지우지 않음. 원래 채널명·사이트로 대상을 찾으므로 이 두 값을 새 표시명으로 바꾸지 말 것.

priority는 양의 정수 또는 보조 전원 같은 구분명. 한 사이트에만 입력해도 같은 채널의 모든 사이트에 공통 적용. 사이트마다 다른 값을 입력하지 말 것. group·net은 일치하는 채널·사이트에만 적용. net의 밑줄·대소문자·앞자리 0은 표시명에 그대로 사용하며, 여러 이름으로 나누지 않음.

빈칸이 아닌 priority를 불러오면 PI·CAP·DCR 표와 개별 채널 상세 순서에 적용이 켜짐. group·net만 불러오면 기존 적용 상태 유지. 수식·잘못된 값·중복 대상·같은 채널의 상충하는 순위가 있으면 전체 불러오기를 중단하며 일부만 변경하지 않음. 값은 수식 없이 직접 입력할 것.

보고서 표시명 적용 범위와 삭제

net은 보고서에 보일 이름만 변경. PI 요약·상세 표, CAP 수량 표와 DCR 표의 Channel 칸에 입력한 이름을 표시. 여러 사이트를 한 행에 표시할 때 이름이 다르면 사이트와 이름을 함께 표시. CAP 집계와 배치도는 SPD Net (실제 연결)을 사용.

그룹·표시명 설정그래프·Excel 상세 시트 표시
그룹 지정채널 수와 관계없이 그래프 제목과 상세 시트 탭에 그룹명 사용. 위 예의 탭 이름은 전원 A, 표의 채널명은 Core_Power_001.
그룹 미지정 · 모든 사이트의 표시명 동일해당 표시명을 개별 채널의 그래프 제목과 상세 시트 탭에 사용.
그룹 미지정 · 표시명이 비어 있거나 서로 다름원래 채널명 사용.

중복되는 Excel 탭 이름은 이름 (2)처럼 번호로 구분. 탭은 Excel의 글자 수·사용 문자 제한에 맞춰 저장.

표시명 직접 변경·삭제: 2 채널·그룹 → 보고서 표시명 열에서 입력하거나 내용을 지운 뒤 미리보기 갱신을 실행할 것. Excel의 빈 net 셀은 기존 표시명을 유지하므로 삭제는 이 열에서 직접 수행할 것. 표시명 변경만으로 실제 연결 확인 상태는 바뀌지 않음.

4. CAP 용량과 활성 상태

3 CAP·DCR → CAP에서 이름과 모델 주석의 판독값을 나란히 확인합니다. 부품이 실제로 할당받은 모델을 따라가며, 모델에 들어 있는 개별 SPICE C 소자의 값을 명목 용량으로 더하거나 대체하지 않습니다. 등가회로 내부 C 값은 제품의 명목 용량과 다를 수 있습니다.

용량 적용 순서

  1. 부품별 수정의 해당 RefDes 개별 수정값
  2. 모델별 일괄 수정의 모델 수정값
  3. 할당된 모델 주석의 명목 용량: Property : C = …, 없으면 Description의 용량
  4. 모델 이름에서 읽은 용량

예를 들어 이름은 CAP_220N인데 명목 주석은 2.2[uF]이면 두 근거와 충돌을 표시합니다. 자동값은 주석을 우선하며, 실제 의도를 확인한 뒤 220 nF 또는 2.2 uF처럼 수정합니다. 수정 칸을 비우면 그 단계의 수정값만 지워지고 다음 순서의 값이 적용됩니다.

부품별 수정은 검색 결과 중 최대 500개를 표시합니다. RefDes 또는 모델로 검색해 대상을 좁히세요.

모델별 일괄 수정에는 실제 CAP 부품에 할당된 모델만 표시합니다. 개별 용량을 수정하면 현재 용량 열에도 바로 반영됩니다. 보고서의 CAP 수량 표는 작은 용량부터 정렬하며 미확인 항목은 마지막에 표시합니다.

수량에 들어가는 부품

AutomaticEnabled와 동일하게 포함합니다. 모델이 비어 있어도 활성 상태는 바뀌지 않으며, 용량을 모르면 Unknown으로 집계합니다.

선택한 채널의 전원–접지에 연결된 활성 CAP를 사이트·채널별로 집계합니다. 명시된 alias로 이어지는 Net도 확인하며, 같은 채널에 동일 RefDes를 중복 집계하지 않습니다. 용량 미확인은 0F로 바꾸지 않고 Unknown 항목으로 분리합니다.

5. DCR 가져오기와 직접 입력

채널 순위 설정…에서 순위 적용을 켜면 DCR 입력 표, 가져오기 확인창, 보고서 미리보기와 Excel 시트에 같은 채널 순서가 적용됩니다. 숫자 한 열을 붙여넣을 때는 선택한 사이트·채널 순서로 값을 먼저 연결한 후 화면에 순위순으로 표시합니다.

DCR 표의 표시·저장 단위는 항상 mΩ입니다. 입력 단위로 mΩ, Ω, µΩ를 선택할 수 있습니다. Excel 머리글에 단위가 있으면 그 단위를 우선 사용하고, 없으면 선택한 입력 단위를 사용합니다. 예를 들어 0.003 Ω는 3 mΩ입니다. 값은 0 이상의 유한한 숫자여야 합니다.

Excel 표 가져오기

  1. 2 채널·그룹에서 가져올 대상의 원래 사이트·채널을 확인합니다. DCR만 만들 때는 이 단계를 생략할 수 있습니다.
  2. 3 CAP·DCR → DCR → Excel 표 가져오기…에서 .xlsx 파일과 시트를 선택합니다.
  3. IRDrop 측정표는 Name을 채널, SITE를 사이트, 마지막 DCR_IRDrop[mΩ] 열을 DCR로 읽습니다. 전류·전압 열은 그대로 두세요. DCR 열이 수식이면 Excel에서 계산 후 저장할 것. 파일에 저장된 계산 결과를 읽습니다.
  4. 일반 측정표는 Site·Channel·DCR 머리글을 포함할 것. 한글 사이트·채널(또는 채널명)도 사용 가능. 행·열 순서는 자유이며 비고 등 추가 열은 무시합니다.
  5. 측정표의 채널에는 원래 채널명 또는 해당 사이트의 보고서 표시명을 사용할 수 있습니다. 채널 양식의 net 열에 표시명을 입력했다면 2 채널·그룹에서 양식을 먼저 불러오세요. 사이트 0은 SITE0과 연결됩니다. 중복 측정값이나 구분할 수 없는 이름은 해당 행에서 확인하세요.
  6. DCR 가져오기 확인 창에서 사이트별 원래 채널명, 보고서 표시명과 mΩ 값을 확인합니다. 측정표에 일부 선택 채널이 빠져 있어도 가져올 수 있습니다. 확인하면 기존 DCR 표 전체를 이번에 읽은 값으로 교체합니다. 미입력 항목에 있던 기존 값도 삭제됩니다. 취소하면 기존 표를 유지합니다.

표를 붙여넣거나 숫자 한 열로 가져오기

Excel에서 사이트·채널·DCR 머리글이 포함된 표를 복사한 뒤 붙여넣기를 누르면 표의 키로 대상을 연결합니다. 기존 대상 매핑이 없어도 키가 포함된 표로 DCR만 가져올 수 있습니다. 숫자만 한 열 복사는 기존 방식으로 사용할 수 있습니다. 이때는 2 채널·그룹에서 대상 행을 추가하고 사용을 체크한 뒤, 입력 단위와 사이트 → 채널 또는 채널 → 사이트 순서를 지정합니다. 대상은 중복을 제거해 이름 순으로 정렬합니다. 복사한 값 수와 선택 대상 수가 다르면 가져오지 않습니다.

SPD·Touchstone 없이 DCR만 만들기

파일 읽기를 생략하고 키가 포함된 표를 붙여넣기 또는 Excel 표 가져오기…로 가져오거나, DCR의 행 추가로 사이트·채널·DCR(mΩ)을 직접 입력하면 됩니다. 숫자 한 열 방식은 먼저 채널 추가로 대응할 사이트·채널을 만든 다음 사용하세요. 같은 사이트·채널의 DCR은 하나만 둘 수 있습니다.

6. 미리보기와 Excel·PNG 저장

미리보기 갱신은 현재 설정으로 표와 그림을 다시 만듭니다. 설정을 바꿨다면 다시 갱신하세요. 선택 목록에서 그림 · … 또는 표 · …를 고릅니다. 표 미리보기는 앞 40행·최대 40열이며, 전체 데이터는 저장한 Excel에서 확인합니다.

새 입력을 읽거나 다른 프로젝트를 열면 이전 미리보기를 비웁니다. 현재 입력의 결과는 미리보기 갱신으로 다시 만드세요.

임피던스 곡선은 모두 실선이며 색으로 구분합니다. 1 입력 → 보고서 정보 → 그래프 선 굵기에서 1.0~5.0 pt를 선택하세요. 화살표는 0.5 pt씩 조절하며 소수 첫째 자리까지 직접 입력할 수 있습니다. 기본값은 1.0 pt입니다. 선택한 굵기는 미리보기·PNG·Excel에 적용되며 프로젝트와 함께 저장됩니다.

Excel은 흰 셀 배경, 숨긴 격자선, 맑은 고딕과 얇은 검정 테두리를 사용합니다. 요약 시트의 제목은 A1, 표는 B4에서 시작합니다. 개별·그룹 상세 시트는 A1을 비우고 그래프를 B2, 수치 표를 P4에 배치하며 틀 고정은 사용하지 않습니다. 표는 기본 11pt, CAP 채널명은 사이트가 많은 표에서 12pt입니다. 100MHz 수치는 PI 주파수 표에서 굵게 표시합니다.

사이트가 8개 이하면 채널·사이트를 세로로 나열하고, 9개 이상인 PI 요약은 채널별 표를 가로로 최대 4개씩 배치합니다. CAP 수량은 용량별 제목과 사이트 행을 두 줄로 구성합니다. 오른쪽 수치 표에도 같은 NET 표시명을 사용합니다.

제품명·작성일·Revision은 프로젝트에 보관합니다. Excel 시트의 3행은 비워 두고 표 밑에 계산 설명이나 경고를 추가하지 않습니다. 입력 관련 경고는 프로그램 로그와 검증 결과에서 확인할 수 있습니다.

7. 배치도 읽는 방법

Excel의 CAP_배치도면 시트에는 왼쪽에 Top, 오른쪽에 Bottom이 있습니다. 미리보기에서는 각각 CAP Top과 CAP Bottom을 선택할 수 있습니다. 해당 면에 표시할 부품·패드 좌표가 없으면 그림에 안내를 표시합니다. 사용하지 않을 면은 Excel에서 그 그림만 선택해 삭제하세요.

배치도는 모든 CAP를 실장한 것으로 가정한 위치도입니다. 검정 배경에 SPD의 좌표·회전·면·몸체 치수를 반영합니다. 선택한 Net의 CAP 자리는 용량별 색으로, 다른 부품은 회색 윤곽선으로 표시합니다. 용량을 알 수 없는 CAP 자리는 보라색입니다.

선택한 CAP의 몸체에는 짙은 외곽선을, 몸체 치수가 없어 패드만 표시하는 경우에는 패드 가장자리에 선을 그립니다. 범례에서 색과 기호의 의미를 확인할 것. 실장 상태를 반영한 수량은 CAP_수량 시트에서 확인할 것.

  • 몸체 치수가 없으면 실제 핀 범위를 사용하고, 핀 정보도 없으면 위치 마커로 표시합니다. 이름이나 패키지 숫자로 몸체 크기를 만들어 넣지 않습니다.
  • 부품에 연결된 Node와 PadStack의 표면 패드를 실제 좌표·회전으로 표시합니다. 원·정사각형·직사각형·다각형을 지원하며, 안티패드와 지원하지 않는 형상은 그리지 않습니다.
  • 좌표가 없는 부품은 그림에서 생략합니다. 이는 CAP 수량에서 빠진다는 뜻은 아닙니다.
  • 정확한 보드 외곽선이 없으면 부품 배치만 표시합니다. 동박 다각형이나 부품 범위를 실제 보드 경계로 단정하지 않습니다.
  • 1 입력 → Bottom 방향의 체크를 켜면 Bottom을 하면에서 본 방향으로 좌우 반전합니다. 끄면 SPD 좌표 방향을 유지합니다. 도면 비교 시 같은 관찰 방향인지 확인하세요.

부품과 연결된 표면 패드를 표시하는 배치도입니다. 전체 동박·배선·실크와 부품에 연결되지 않은 비아는 재현하지 않습니다. 따라서 원본 CAD 화면과 완전히 같은 그림은 아닙니다.

8. 임피던스 계산과 보고서 단위

각 주파수에서 전체 S 행렬을 먼저 Z 행렬로 변환합니다. 포트 사이 결합을 포함하므로 다중 포트에서 Sii만 떼어 1포트 식을 적용하지 않습니다.

Z = R · (I − S)−1 · (I + S)
  • S: 해당 주파수의 복소 S 파라미터 행렬. RI는 실수부·허수부, MA는 크기·각도(도), DB는 20log10 크기·각도(도)로 복원합니다.
  • I: 포트 수와 같은 크기의 단위행렬.
  • R: Touchstone 옵션 행의 공통 기준 저항(Ω). 양의 실수 하나를 모든 포트에 적용합니다. 생략 시 50Ω입니다. 포트별로 다른 기준 임피던스·복소 기준 임피던스는 지원하지 않습니다.
  • Zii: 변환된 Z 행렬의 i번째 대각 성분. 다른 포트의 전류가 0인 Z 파라미터 정의에 따른 자기 임피던스입니다.
  • |Zii|: √(Re(Zii)2 + Im(Zii)2). 보고서 표·그래프에 표시하는 값입니다.

가상 1포트 예에서 R=50Ω, S=0.5이면 Z=50×(1+0.5)/(1−0.5)=150Ω입니다. 여러 포트에서는 위의 행렬식을 사용합니다. 행렬이 특이하거나 계산 결과가 유한하지 않으면 해당 주파수의 값을 생략하고 경고합니다.

기준 주파수의 값

표의 기준점은 100kHz, 1MHz, 10MHz, 100MHz, 1GHz입니다. 정확한 표본이 있으면 그 복소 Zii의 크기를 사용합니다. 없으면 양옆 표본 사이에서 주파수에 대해 복소 Zii를 선형 보간한 뒤 크기를 구합니다. 로그 주파수나 |Z| 크기만을 보간하는 방식이 아닙니다.

보간된 표 값은 숫자 뒤에 *를 붙입니다. 그래프 표시 범위는 1kHz ~ 2GHz와 원본 주파수 범위가 겹치는 구간입니다. PI 요약 시트 2행에 이 범위를 표시합니다.

그래프는 주파수가 10배가 되는 구간마다 최소 30간격을 사용합니다. 이웃한 표시 주파수의 비는 최대 약 1.0798입니다. 원본 점을 유지하며 넓은 간격에만 표시용 보간점을 추가합니다. 추가 점은 주변 복소 임피던스로 계산한 값입니다. 실제 측정·시뮬레이션의 주파수 해상도는 원본 파일로 결정됩니다.

t = (f − f₁) / (f₂ − f₁)
Zii(f) = Zii(f₁) + t · [Zii(f₂) − Zii(f₁)]

입력 주파수 범위 밖은 외삽하지 않고 빈 셀로 둡니다. 양옆 값 중 하나가 유효하지 않아도 빈 셀입니다. 로그 그래프에는 양의 주파수·양의 유효 크기만 표시합니다.

단위와 100MHz 통계

MLO의 임피던스는 항상 mΩ로 표시합니다. PCB 표는 표마다 단위를 정합니다. 표에 표시할 임피던스가 모두 1 Ω 미만이면 mΩ로 환산합니다(예: 0.022 Ω → 22 mΩ). 하나라도 1 Ω 이상이면 Ω로 표시합니다. 빈 측정값은 계산에서 제외합니다. PCB 그래프는 선택한 모든 측정 포트의 100 MHz 임피던스가 1 Ω 미만이면 mΩ, 그 밖에는 Ω로 표시합니다. DCR은 항상 mΩ입니다.

MAX는 채널별 유효한 사이트 값의 최댓값, AVG는 그 값들의 산술평균, 편차는 (MAX − AVG) / AVG입니다. 빈 사이트는 평균에서 제외하며 AVG가 0이면 편차는 공란입니다. Priority나 별도 목표값에 따른 합격·불합격 판정은 하지 않습니다.

9. 프로젝트 저장과 원본 변경 확인

파일 → 프로젝트 저장… 또는 Ctrl+S로 .report.json을 저장합니다. 보고서 설정, 연결·그룹·보고서 표시명·확인 상태, CAP 수정값, DCR 표, 입력 파일 경로와 서명을 보관합니다. 원본 SPD·Touchstone이나 계산 결과 전체를 프로젝트 안에 복사하지 않습니다.

프로젝트 열기…는 Ctrl+O, 새 프로젝트는 Ctrl+N입니다. 다른 PC로 옮길 때는 입력 파일도 함께 준비하고 경로를 확인하세요.

원본 서명은 파일 크기와 수정 시각입니다. 열 때 원본이 없거나 서명이 바뀌면 매핑을 다시 확인하도록 합니다. 읽는 중·출력 전에 변경을 발견한 경우에도 파일을 다시 읽고 연결을 확인해야 합니다. 서명은 내용 전체의 암호학적 해시는 아닙니다.

다른 입력 파일로 교체하거나 변경된 원본의 프로젝트를 열면 이전 DCR 값을 비웁니다. 새 입력에 맞는 DCR을 다시 가져오세요. 가져온 DCR Excel 원본에는 보고서를 덮어쓸 수 없습니다.

10. 결과가 예상과 다를 때

사용할 단자를 확인하라는 메시지

2 채널·그룹에서 같은 사이트·채널의 중복 후보를 검색하세요. 남길 단자를 하나 선택하고 다른 행의 사용을 해제한 뒤 확인합니다. 표시 순서나 포트 번호만으로 단자를 선택하지 마세요.

기존 보고서와 CAP 용량·수량이 다름

원본 설계·모델 할당의 Revision, Disabled 포함 여부, NULL·빈 모델 여부와 수동 수정값을 비교하세요. 예를 들어 과거 보고서는 220nF로 적혀 있어도 현재 할당 모델 주석이 2.2uF일 수 있습니다. 프로그램은 기존 보고서의 숫자에 맞추려고 현재 원본 값을 바꾸지 않습니다. 의도한 명목 용량을 확인한 뒤 수정값을 적용하세요.

PI 표가 비거나 일부 페이지가 없음

Touchstone을 읽었는지, 사용·요약·확인이 켜져 있는지, 기준 주파수가 입력 범위에 들어가는지 확인합니다. 하단 로그에 포함·제외 페이지와 계산 실패 사유가 표시됩니다.

DCR 개수가 맞지 않음

머리글이 있는 표는 확인창에서 미입력으로 표시된 사이트·채널을 원본 측정표와 대조할 것. 숫자 한 열만 붙여넣을 때는 선택한 대상 수만큼의 값을 지정한 순서로 복사하세요.

저장할 수 없음

대상 Excel 파일이 다른 프로그램에서 열려 있는지, 폴더에 저장할 수 있는지 확인합니다. 입력 파일을 출력 경로로 선택하지 마세요. 입력과 연결을 수정했다면 미리보기를 다시 갱신한 뒤 저장하세요.

11. 화면 입력 없이 생성하고 검증하기

저장해 둔 프로젝트로 보고서를 반복 생성할 때는 명령줄 검증 도구를 사용할 수 있습니다. 화면과 동일한 SPD·Touchstone 판독기, 매핑 검사, 계산식과 Excel 출력 코어를 실행합니다. 마우스나 키보드 입력은 필요하지 않습니다.

설치한 프로그램에서 실행

PowerShell에서 다음 명령의 프로젝트·출력·참조 경로를 실제 파일 경로로 바꾸세요. 공백이 있는 경로는 따옴표로 감쌉니다.

& "$env:ProgramFiles\SPD Report Generator\SPD Report Generator.exe" `
  --validate-project "D:\Work\example.report.json" `
  --output "D:\Work\checked.xlsx" `
  --reference "D:\Work\reference.xlsx"

--reference는 선택 사항입니다. 참조 보고서가 없어도 계산 결과와 출력 셀을 대조합니다. 소스에서 실행하려면 같은 인자로 python scripts/validate_reports.py를 사용하세요.

결과 확인

Excel과 같은 폴더에 checked.validation.html, checked.validation.json이 생성됩니다. HTML을 열면 PI·100MHz·상세 표·CAP·DCR의 일치 수와 차이, 제외 페이지, 글꼴·채우기·틀 고정·그림 수를 확인할 수 있습니다. 입력 파일이 크면 완료까지 시간이 걸립니다.

채널·사이트·주파수·용량을 기준으로 비교하므로 행 순서가 달라도 대응합니다. 참조와 값이 다르면 먼저 원본 Revision과 선택 단자·CAP 수정값을 확인하세요. 참조 숫자에 맞추어 계산값을 바꾸지는 않습니다.

원본이 변경되거나 매핑 확인이 필요한 프로젝트는 자동으로 승인하지 않고 중단합니다. 프로그램에서 연결을 확인하고 프로젝트를 다시 저장하세요. 검증 도구는 원본·참조·프로젝트에 결과를 덮어쓰지 않습니다. 입력 경로와 채널명이 담긴 검증 결과도 설계 자료처럼 로컬에 보관하세요.
